### خط لوله‌ی فریم (مسیر GPU، فاز ۲)
```
رندر CPU (flatOnly) → فریم زمین (شیدر گل‌آلای: ambient رنگی + lightSum + sunAt + AO/relief)
  → آپلود تکسچر زمین → پاس دکال: AO تماس + کارت‌های نور (mode 3، بی‌نور) زیر همه‌ی اشیا
  → y-sort: اسپرایت‌ها (نورپذیر) با emissive برای پنجره/شعله/نخبه
  → لایه‌ی fx (مقیاس‌شده) → لایه‌ی باران (۱:۱) → UI دانجن (اسپلش طبقه/مینی‌مپ) → اورلی (fade + وینیت)
```

## ۵) باگ‌هایی که در مسیر پیدا و رفع شد (درس‌ها)

1. **حوضه‌های نور معکوس بودند** (نور ضعیف‌تر از اطراف): `pushPool` الگوی تخصیص ایمن نداشت و در شب `Cannot set properties of undefined` می‌داد → مرگ حلقه‌ی رندر و اعداد دروغین در تست. رفع: الگوی `DEC[dn] || (DEC[dn] = {})`.
2. **نگهبان حلقه**: خطای یک فریم GPU نباید بازی را قفل کند → try/catch روی `glScene` و افت خودکار به CPU (`_glBad`).
3. **نرمال پیکسل‌آرت خرد می‌شد**: گرادیان ۱px با relief ۱۸ → n.z≈۰٫۵ یعنی هم N·L، هم AO، هم sunAt نابود می‌شدند. رفع: گام ۲px + clamp ±۰٫۲۲ + relief ۷ + کف AO ۰٫۸۲.
4. **N·L روی سطح تخت حوضه نمی‌سازد** → تصمیم معماری: «کارت نور» (lightmap رویه‌ای، mode 3) مثل خود HD-2D.
5. بیلدر بی‌سینتکس‌چک است و exportهای از دست‌رفته (VS_OVL/FS_OVL/VS_LAY) فقط در بوت مرورگر لو می‌روند → بوت jsdom/Chromium بعد از هر بیلد الزامی.

## ۷) چه چیزی به هدف نخورد (فهرست صادقانه)

- **بلوم و god-ray نداریم** (مورد ۳ نصف‌نمره)؛ نور سایه‌ی واقعی (shadow map) و بازتاب رنگی (bounce) ندارد → تقاطع‌ها می‌توانند نشتی نور داشته باشند.
- **DOF واقعی نه** (مورد ۲ = ۰ در هر دو فاز).
- **رمپ ۴–۵ پله‌ی هیو-شیفت + sel-out برای اسپرایت‌ها** انجام نشد (فاز هنر اسپرایت جدا می‌خواهد).
- تایل‌ست هنوز گذار ۴۷-blob ندارد؛ باد/آب ساده؛ پراپ‌های بلند بی‌پارالاکس (بیлборд) باقی ماندند.
- کارت‌های نور «نور واقعی» نیستند: ترکیب additive نیست و سایه نمی‌سازند (اما ارزان و پایدار هستند و روی SwiftShader هم یکسان‌اند).
